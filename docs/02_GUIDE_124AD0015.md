## Concepts to learn before you start

- **Embedding layer** — turns a symbol (a letter, a token) into a list of numbers the network can do math on. Both your drug text and protein sequence need to be embedded before anything else happens.
- **1D CNN (Convolutional Neural Network) over sequences** — slides a small window across your sequence, learning to detect short repeating local patterns (like a specific 3-5 letter motif). Good at picking up local structure quickly.
- **BiLSTM (Bidirectional LSTM)** — reads your sequence left-to-right and right-to-left at the same time, so each position's representation is informed by context from both directions, not just what came before it.
- **Multi-head attention** — instead of one single "importance score" per position, the model learns several different scoring patterns in parallel ("heads"), each potentially picking up on a different kind of relationship. The output tells you, for each position, how much the model focused on it.
- **Cross-attention / fusion** — once you have a representation of the drug and a representation of the protein, you need a layer that lets them "look at each other" to decide which drug parts interact with which protein parts. This is where the actual interaction prediction comes from.
- **Loss function and training loop** — the standard machine learning cycle: make a prediction, measure how wrong it was (loss), adjust the model's weights slightly (via an optimizer like Adam), repeat over many batches and epochs.

# PART 1 — SOLO WORK

## Step 1: Build the drug encoder

Turn a SMILES string into a fixed-size vector. The simplest solid approach: treat SMILES as a character sequence, embed each character, and run it through a small 1D CNN.

```python
import torch
import torch.nn as nn

class DrugEncoder(nn.Module):
    def __init__(self, vocab_size, embed_dim=128, out_dim=128):
        super().__init__()
        self.embedding = nn.Embedding(vocab_size, embed_dim)
        self.conv1 = nn.Conv1d(embed_dim, 64, kernel_size=4)
        self.conv2 = nn.Conv1d(64, 96, kernel_size=6)
        self.conv3 = nn.Conv1d(96, out_dim, kernel_size=8)
        self.pool = nn.AdaptiveMaxPool1d(1)

    def forward(self, x):
        # x: (batch, seq_len) integer-encoded SMILES characters
        x = self.embedding(x).permute(0, 2, 1)   # (batch, embed_dim, seq_len)
        x = torch.relu(self.conv1(x))
        x = torch.relu(self.conv2(x))
        x = torch.relu(self.conv3(x))
        x = self.pool(x).squeeze(-1)              # (batch, out_dim)
        return x
```

You'll need a small character-to-integer vocabulary for SMILES (build this from all unique characters seen across the dataset — usually under 70 characters total, so this is quick).

## Step 2: Build the protein encoder — this is the important one

This is where you mirror the PCLAtt-style architecture: parallel CNN-BiLSTM, then multi-head attention. **Keep the attention weights accessible in the output** — 124AD0067 needs them for evaluation, so don't let the model swallow them internally.

```python
class ProteinEncoder(nn.Module):
    def __init__(self, vocab_size, embed_dim=128, hidden_dim=128, n_heads=8):
        super().__init__()
        self.embedding = nn.Embedding(vocab_size, embed_dim)
        self.conv = nn.Conv1d(embed_dim, hidden_dim, kernel_size=8, padding='same')
        self.bilstm = nn.LSTM(hidden_dim, hidden_dim // 2, bidirectional=True, batch_first=True)
        self.attention = nn.MultiheadAttention(hidden_dim, n_heads, batch_first=True)

    def forward(self, x):
        # x: (batch, seq_len) integer-encoded amino acids
        x = self.embedding(x)                      # (batch, seq_len, embed_dim)
        x = torch.relu(self.conv(x.permute(0, 2, 1))).permute(0, 2, 1)
        x, _ = self.bilstm(x)                       # (batch, seq_len, hidden_dim)
        attn_out, attn_weights = self.attention(x, x, x)
        # attn_weights: (batch, seq_len, seq_len) — save this, it's the explanation
        return attn_out, attn_weights
```

## Step 3: Build the fusion layer and prediction head

```python
class ColdSiteDTI(nn.Module):
    def __init__(self, drug_vocab, protein_vocab):
        super().__init__()
        self.drug_encoder = DrugEncoder(drug_vocab)
        self.protein_encoder = ProteinEncoder(protein_vocab)
        self.cross_attention = nn.MultiheadAttention(128, 8, batch_first=True)
        self.predictor = nn.Sequential(
            nn.Linear(128, 64), nn.ReLU(), nn.Dropout(0.2), nn.Linear(64, 1)
        )

    def forward(self, drug_input, protein_input):
        drug_vec = self.drug_encoder(drug_input)                     # (batch, 128)
        protein_seq, protein_self_attn = self.protein_encoder(protein_input)
        # let the drug "query" the protein sequence to find interaction points
        fused, cross_attn_weights = self.cross_attention(
            drug_vec.unsqueeze(1), protein_seq, protein_seq
        )
        # cross_attn_weights is your real explanation signal — this is what
        # 124AD0067's precision@k evaluation will use
        pred = self.predictor(fused.squeeze(1))
        return pred, cross_attn_weights
```

**This is a working starting skeleton, not a finished model.** Expect to tune layer sizes, add normalization layers, and experiment once real data is flowing. The important structural decision — parallel CNN+BiLSTM then attention for the protein side, and a cross-attention fusion that outputs interpretable weights — is already right; everything else is refinement.

## Common mistakes to avoid

- Forgetting to keep attention weights accessible outside the model — if they're only used internally and discarded, 124AD0067 has nothing to evaluate. Design for this from the very first version.
- Training on the wrong split file by accident (e.g., accidentally mixing cold-drug and cold-target data) — name your saved checkpoints and logs very explicitly by split type.
- Chasing a slightly higher accuracy number for weeks — remember the model's job here is to be a solid, reasonable, comparable predictor; the paper's real contribution is the interpretability-under-cold-start measurement, not beating every baseline on raw accuracy.
